## 1. 설치할 것

`pyproject.toml`에 빠져있어서 별도로 설치 필요:

```powershell
pip install python-dotenv Pillow
```

- `python-dotenv` — `webapp/settings.py`가 `.env` 로드에 사용
- `Pillow` — `pets` 앱의 `ImageField`에 필요

**Docker Desktop 설치** — nginx 컨테이너 실행용

---

## 2. `.env` 파일 (프로젝트 루트)

```env
DJANGO_SECRET_KEY=<아래 명령어로 발급>
DJANGO_DEBUG=true
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1

DJANGO_DATABASE_URL=mysql+pymysql://root:mysql80@127.0.0.1:3306/pettriage
DATABASE_URL=mysql+pymysql://root:mysql80@127.0.0.1:3306/pettriage
JWT_SECRET_KEY=<위와 동일하게 발급>

INFERENCE_INTERNAL_URL=http://127.0.0.1:8001
```

SECRET 키 발급:
```powershell
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

---

## 3. DB 마이그레이션

```powershell
python manage.py migrate auth
python manage.py migrate sessions
python manage.py migrate contenttypes
python manage.py migrate admin
```

전체 `migrate` 는 pets/diary 스키마 충돌 나므로 위 4개만.

---

## 4. 실행 (3개 터미널)

```powershell
# 터미널 1 — Django
python manage.py runserver 8000

# 터미널 2 — FastAPI
uvicorn src.pettriage.app.main:app --port 8001

# 터미널 3 — nginx (최초 1회)
docker compose up nginx -d
```

접속: `http://localhost/`
