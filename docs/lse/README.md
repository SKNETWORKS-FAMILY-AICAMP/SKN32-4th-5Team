# `docs/lse` — 이서은 기여 원본

이 폴더는 **받는 곳이지 정본이 아니다.**

팀원이 각자 만든 자료를 여기 올리고, 팀장이 검토해 공식 문서(`docs/10`~`docs/14`)에
반영한다. 원본은 지우지 않는다 — 기여 근거이고, 공식 문서가 출처로 가리킨다.
`docs/lgj/` 도 같은 자리다.

|---|---|---|

## 🔴 화면을 고칠 때 여는 파일은 이것이 아니다

**정본은 `docs/11_화면설계서.md` 다.** 두 문서가 어긋나면 `docs/11` 이 이긴다 (D-22).

ID 도 다르다 — 덱은 `SC-001`·`FR-AUTH-002`, 정본은 `SC-01`·`FR-03` 을 쓴다.
추적표(`docs/10 §7`)와 `scripts/check_requirements.py` 는 **정본 ID 만** 안다.
대응표는 **`docs/11 §9.1`** 에 있다.

## 흡수 결과 — 덱이 `docs/11` 에 남긴 것

- **§1.3 진입 경로** — 화면마다 *어떻게 닿는가* 를 세운 축. `docs/11` 에 없던 것이라 그대로 받았다
- **`docs/10` UC-10 · FR-23~26** — 대화 이력 화면의 요구사항. 덱 9·10쪽이 이것을 처음으로
  글로 적었고, 그 덕에 `docs/11 §7` 의 빈칸 둘이 닫혔다

## 덱에 남은 정정 넷

`docs/11 §9.1` 의 표를 그대로 옮긴다. **슬라이드도 고쳐야 두 문서가 같은 말을 한다.**

1. **6쪽** — SC-003 진입 경로가 *"로그인 직후 기본 진입 화면"* 인데 **2쪽과 어긋난다.**
   실물은 `LOGIN_REDIRECT_URL = "/chat/"` 라 **2쪽이 맞다**
2. **9 · 10쪽** — 동작하는 화면으로 적었지만 지금은 **503** 이다 (표가 다른 DB 에 있다 · D-105).
   *못 하는 것을 한다고 적지 않는다* (D-58)
3. **9쪽** — 목록이 *"본인 소유 세션 전부"* 가 아니라 **활성 반려동물 기준으로 좁혀졌다**
   (2026-08-27 `ksr` 흡수 · `docs/11 §4.4.1`)
4. **7쪽** — 사진에 **D-43 관문**이 빠졌다. 5MB · 1280px · EXIF 제거 · JPEG 재인코딩
   (`docs/11 §4.2.1`)

나머지는 실물과 맞다 — 응급도 4단계 이름, 체중 급변 5%/10%, 남의 세션 404,
세션 인증, 리포트 흐름. 코드로 대조했다.

## ⚠️ 슬라이드는 자주 고치지 않는다

`.pptx` 는 **diff 가 안 된다.** PR 에서 무엇이 바뀌었는지 볼 수 없고, 고칠 때마다
파일 전체(약 67KB)가 새로 쌓인다.

- 내용이 바뀌었으면 **먼저 `docs/11` 을 고친다**
- 슬라이드는 **발표 직전에 한 번** 맞춘다
- 고칠 때 커밋 메시지에 **무엇을 고쳤는지 글로 적는다** — diff 가 대신 말해 주지 않는다
