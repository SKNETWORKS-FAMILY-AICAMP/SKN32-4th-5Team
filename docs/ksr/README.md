# `docs/ksr` — 권소라 기여 원본

이 폴더는 **받는 곳이지 정본이 아니다.**

팀원이 각자 만든 자료를 여기 올리고, 팀장이 검토해 공식 문서(`docs/10`~`docs/14`)에
반영한다. 원본은 지우지 않는다 — 기여 근거이고, 공식 문서가 출처로 가리킨다.

## 흡수 결과 — 이 보고서가 프로젝트를 바꾼 것 셋

**① 테스트 층이 넷에서 다섯으로 늘었다.** `docs/13 §1` 에 **⑤ 수동 UI** 가 생겼다.
Django 앱 자동화 테스트가 0건인 동안 **화면을 실제로 만져 본 유일한 층**이다.

**② 실제 버그를 잡았다.** `Pet.Meta` 에 `ordering` 이 없어 `.first()` 가 랜덤 UUID
순으로 동작하고 있었다. `.first()` 에 기대는 화면이 셋이었고, `ordering = ["created_at"]`
로 고쳤다 (`pets/models.py`).

> 자동화가 못 잡는 종류다 — 테스트는 초록이고, 펫이 하나뿐이면 영원히 안 드러난다.
> *"우연히 맞는다"* 를 알아보는 건 지금으로선 사람뿐이다.

**③ 우리 문서의 오류를 드러냈다.** TC-FR-HIST-001~004 가 통과인데 `docs/11 §4.5` 는
503 이라고 단언했었다. **우리 쪽이 틀렸다** — 환경 의존적인 사실(DB 를 몇 개로 두는가)을
절대적으로 적었다. 정정했다.

## 최종본이 바꾼 것 — 미실행 19건 → 4건

인프라 15건(`TC-NFR-*`)을 **실제 배포에 대고** 쟀다. 배포가 끝나 있었기에 가능했고
(`docs/12 §6`), 그 덕에 **`docs/10 §6` 의 `⬜` 여섯 개가 실측으로 채워졌다** —
NFR-13 · 14 · 16 · 18 · 21 · 22. 요구사항 문서의 경고가 24건에서 18건으로 줄었다.

**두 판을 다 남긴 이유** — 무엇이 어떻게 바뀌었는지 셀 수 있어서다. `.xlsx` 는 diff 가
안 되니, 판본을 지우면 그 변화는 아무도 다시 못 본다. `요구사항정의서` 쪽에서
**v3→v4 사이에 요구사항 한 줄이 사라진 것**도 두 판이 남아 있어서 겨우 알았다.

## 🔴 한 줄은 받지 않았다 — `TC-NFR-PERF-001`

상태는 **통과**인데 실제결과는 이렇게 적혀 있다.

> *"별도 정적 파일을 운영 경로에서 제공하는 구성은 **현재 적용하지 않았음** …
> Nginx 정적 서빙은 **검증 대상에서 제외함**"*

**안 했고 안 쟀다고 적어 놓고 상태가 통과다.** *"우리 잘못이 아니니까"* 가 통과로
번역된 자리로 보인다. **요구사항을 못 채운 것과 요구사항이 필요 없는 것은 다르다** (D-58).

그리고 근거가 된 *"정적 파일 참조가 없다"* 도 절반만 맞다. 우리 템플릿은 그렇지만
**`django.contrib.admin` 이 켜져 있고 관리자 화면은 명세의 SC-07** 이다. Django 관리자는
자기 CSS 를 `/django-static/admin/…` 에서 가져오는데, `DEBUG=false` 면 Django 가 안 내주고
`nginx.conf` 에는 그 블록이 없다 → **배포된 `/admin/` 은 CSS 없이 뜬다.**

확인은 간단하다 — 배포 도메인에서 `/admin/` 을 열어 보면 된다.
판정 근거는 `docs/10 §6.1`, 고치는 일은 D-107 ①과 같은 작업이다.

> **이 한 줄이 나머지 33건의 값어치를 깎지 않는다.** 오히려 반대다 — 34건이 관측값과
> 함께 적혀 있어서 **이 한 줄만 결이 다른 것이 눈에 띄었다.**

   그것**이고(`docs/11 §4.5`), 동시에 D-104 의 경계가 배포에서 무너져 있다는 뜻이다. 7b 입력

## ⚠️ `.xlsx` 는 자주 고치지 않는다

diff 가 안 된다. PR 에서 무엇이 바뀌었는지 볼 수 없고, 고칠 때마다 파일 전체가 새로 쌓인다.
실제로 `v3` → `v4` 사이에 **요구사항 한 줄(`NFR-DEPLOY-006` DB 백업)이 소리 없이 사라졌다.**
두 판본이 다 남아 있어서 겨우 알았다.

- 내용이 바뀌었으면 **먼저 `docs/10` 을 고친다**
- 표는 **제출 직전에 한 번** 맞춘다
- 고칠 때 커밋 메시지에 **무엇을 고쳤는지 글로 적는다** — diff 가 대신 말해 주지 않는다
